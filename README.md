# RK Tailoring Major

A web-based tailoring measurement management application designed to efficiently track customer details and garment dimensions.

## Features
- **Customer Dimension Tracking:** Accurately record and manage measurements for various customers.
- **Garment Categories:** Specialized filtering for custom ethnic wear including राजपूती पोशाक, लहंगा कुर्ती, and सलवार सूट.
- **Photo Uploads:** Multi-photo camera upload functionality for capturing design references and fabric details.
- **Authentication:** Integrated Google account login for secure access.

## Tech Stack
- HTML
- CSS
- JavaScript

## Usage
Simply clone the repository and open the `index.html` file in any modern web browser to run the application.
